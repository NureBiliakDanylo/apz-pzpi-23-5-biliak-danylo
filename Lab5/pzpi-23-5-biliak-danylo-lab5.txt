3 ОПИС ВИКОНАНОЇ РОБОТИ
Протягом цього циклу лабораторних робіт відповідно до вимог SRS, було успішно реалізовано наступний функціонал та архітектурні рішення:
1. Серверна частина
- Платформа: Реалізовано на Node.js із використанням фреймворку Express.
- REST API: Створено повноцінний інтерфейс для взаємодії з IoT-пристроями та клієнтськими додатками.
- Автентифікація та безпека: Впроваджено систему авторизації на основі JWT-токенів та хешування паролів (bcryptjs). Реалізовано ролі користувача, адміністратора, молодшого адміністратора, адміністратора БД.
- Робота з даними: Інтегровано реляційну базу даних PostgreSQL. Реалізовано схему для зберігання всієї необхідної для роботи системи інформації про датчики, їх показники та користувачів.
- Прогнозування: Розроблено алгоритм генерації локального прогнозу на основі історичних даних датчика (тренди, мінімуми/максимуми).
2. IoT-клієнт
- Програмне забезпечення: Розроблено прошивку для мікроконтролерів (Arduino/ESP32) мовою C++.
- Передача даних: Реалізовано механізм збору показників з сенсорів та їх відправку на сервер через HTTP POST запити з використанням унікальних API-ключів пристроїв.
- Локальне сховище: Додано підтримку LittleFS для тимчасового зберігання даних у разі відсутності Wi-Fi з'єднання.
3. Веб-клієнт
- Створено сучасний інтерфейс на базі React.
- Реалізовано функціонал відображення поточних показників датчиків на інтерактивних панелях, візуалізації історичних даних за допомогою графіків. Додано модуль реєстрації та керування власними ІоТ-сенсорами. Перегляд короткострокового прогнозу, сформованого сервером. Також, саме веб-клієнт реалізує інтерфейс для всіх функцій адміністрування.
4. Мобільний клієнт
- Розроблено як нативний Android-застосунок на мові Kotlin.
- Забезпечено швидкий доступ до погодних даних та загалом функціоналу звичайних користувачів із мобільних пристроїв.
5. Інфраструктура та віртуалізація
- Контейнеризація: Всю систему розгорнуто за допомогою Docker та Docker Compose, що забезпечує швидке розгортання та ізоляцію сервісів.
- Балансування навантаження: Впроваджено Nginx як Reverse Proxy та Load Balancer.
- Масштабування: Реалізовано можливість горизонтального масштабування API-сервісу з динамічним розподілом запитів.
6. Адміністрування та обслуговування
- Резервне копіювання: Реалізовано функціонал створення SQL-дампів бази даних та можливість їх завантаження через адмін-панель.
- Керування пристроями: Додано можливість реєстрації нових сенсорів, перегляду їх статусу та видалення застарілих пристроїв.
- Документація API: Інтегровано Swagger для напівавтоматичної генерації документації ендпоінтів сервера.
